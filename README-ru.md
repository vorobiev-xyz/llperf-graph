# llperf-graph

[English](README.md) | **Русский**

Интерактивный визуализатор отчётов бенчмарка llperf. Отображает таймлайны активности системы, параллельность и метрики пропускной способности с поддержкой сравнения нескольких отчётов.

## Возможности

- **Таймлайн запросов**: диаграмма Ганта с фазами каждого запроса (загрузка модели, prefill, генерация, накладные расходы)
- **Отслеживание параллельности**: активные запросы по фазам в каждый момент времени
- **Анализ пропускной способности**: суммарная и индивидуальная скорость генерации во времени
- **Статистическое сравнение**: box plot графики для сравнения нескольких запусков
- **Интерактивное исследование**: масштабирование, панорамирование, всплывающие подсказки, выделение запросов
- **Поддержка нескольких отчётов**: загрузка и сравнение множества бенчмарков
- **Двуязычный интерфейс**: полная локализация на английском и русском языках

## Быстрый старт

### Вариант 1: Локальный файл

Откройте `index.html` напрямую в веб-браузере. Используйте кнопку "Добавить отчёт..." или перетащите JSON файлы в окно.

### Вариант 2: Локальный сервер (рекомендуется)

```bash
python3 -m http.server
# Откройте http://localhost:8000
```

Режим сервера обеспечивает:
- Автозагрузку отчётов из манифеста `reports.json`
- URL параметры: `?file=report1.json&file=report2.json`
- Листинг каталога для автоматического обнаружения отчётов

## Использование

### Загрузка отчётов

- **Вручную**: нажмите "Добавить отчёт..." или перетащите JSON файлы в окно
- **Автозагрузка**: разместите `reports.json` в той же директории:
  ```json
  ["report1.json", "report2.json"]
  ```
- **URL параметры**: `?file=report.json` (можно несколько)

### Навигация

- **Колесо мыши** над графиками: масштабирование вокруг курсора
- **Перетаскивание**: сдвиг таймлайна
- **Двойной клик**: сброс на весь запуск
- **Наведение**: синхронизированный курсор на всех графиках с подсказкой
- **Клик по запросу**: переключение выделения
- **Клавиатура**:
  - `←` / `→`: сдвиг таймлайна
  - `+` / `-`: масштабирование
  - `0`: сброс на весь запуск
  - `Esc`: снять выделение

### Интерфейс

- **Вкладки** вверху: переключение между загруженными отчётами
- **×** на вкладке: выгрузить отчёт
- **"Закрыть все"**: выгрузить все отчёты
- **Перетаскивание вкладки**: изменить порядок (влияет на таблицу сравнения)
- **Переключатель языка**: EN/RU в правом верхнем углу
- **Кнопки ?**: контекстная справка для каждой секции

### Представления

#### Вкладка "Сводка"
- **Сравнение запусков**: таблица сравнения всех загруженных отчётов
- **Статистическое сравнение**: box plot графики для скорости генерации и параллельной пропускной способности

#### Вкладка "Детали"
- **Итоги запуска**: карточки с ключевыми метриками
- **Обзор запуска**: миникарта для выбора окна просмотра
- **Что делала система**: графики таймлайна, параллельности и пропускной способности
- **Статистика в окне**: метрики для выбранного временного диапазона
- **Параметры запуска**: конфигурация и вычисленные значения
- **Запросы**: детальная таблица (сортируемая, фильтруемая)

## Формат отчёта

Визуализатор ожидает JSON файлы следующей структуры:

```json
{
  "metrics": [
    {
      "request_start_time_ns": 1234567890,
      "request_end_time_ns": 1234567890,
      "prompt_length": 100,
      "response_length": 50,
      "model_load_ns": 1000000,
      "prompt_processing_ns": 2000000,
      "generation_ns": 5000000,
      "ttft_ns": 3000000
    }
  ],
  "config": {
    "model": "model-name",
    "parallel_size": 4
  },
  "summary": {
    "avg_response_tps": 25.5,
    "p50_response_tps": 24.8,
    "avg_prompt_tps": 1200
  }
}
```

### Обязательные поля (на каждую метрику)
- `request_start_time_ns`: время начала запроса
- `request_end_time_ns`: время завершения запроса
- `prompt_length`: количество токенов промпта
- `response_length`: количество сгенерированных токенов

### Опциональные поля
- `model_load_ns`: время загрузки модели
- `prompt_processing_ns`: время prefill
- `generation_ns`: время генерации
- `ttft_ns`: время до первого токена
- `config`: объект конфигурации модели
- `summary`: предвычисленная статистика

## Модель фаз

Каждый запрос разделён на фазы:
1. **Загрузка модели**: загрузка модели в память
2. **Prefill**: обработка входного промпта
3. **Генерация**: генерация токенов ответа
4. **Накладные расходы**: сеть, очередь, прочие задержки

Фазы вычисляются из временных меток и отображаются разными цветами на таймлайне.

## Метрики

### Вычисляемые метрики
- **Длительность**: время "по стенным часам" от начала первого запроса до конца последнего
- **Параллельность**: среднее количество одновременно активных запросов
- **Суммарная генерация**: пропускная способность системы в ток/с (сумма всей параллельной генерации)
- **Скорость на запрос**: индивидуальная скорость генерации запроса
- **Скорость prefill**: пропускная способность обработки промптов
- **Простой**: время, когда нет активных запросов

### Статистика окна
Все метрики могут быть вычислены для выбранного временного окна при масштабировании таймлайна.

## Локализация

Интерфейс поддерживает английский и русский языки. Выбор языка сохраняется в localStorage браузера.

Чтобы добавить новый язык:
1. Добавьте переводы в объект `LANG` в `app.js`
2. Добавьте секции справки с атрибутом `data-lang` в `index.html`
3. Обновите переключатель языка в шапке
